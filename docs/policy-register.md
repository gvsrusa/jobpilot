# JobPilot AI: Policy Register

Status: draft for owner approval. Register date: 2026-11-01. Source: [master spec](superpowers/specs/2026-11-01-jobpilot-master-spec.md) sections 3, 5, and 9, and [PRD](prd.md). Requirement IDs (`FR-<section>.<n>`) come from the PRD.

**This is an engineering terms review, not legal advice.** It records what the vendors' own documents say and what the product does as a result. Nobody here is a lawyer, and a vendor or court may read a clause differently.

**Terms change.** Several sources below changed within the last two months, and OpenAI's Usage Policies change again on 2026-11-20. Every entry is true only for its date read. Each release must re-read the entries it depends on before it ships (see [Release re-check](#release-re-check)).

## How to read this register

The analyzed case is a desktop app run by a user on their own machine, under their own login, with no JobPilot server between the user and the vendor. The separate case where a hosted service acts for users is listed in its own rows. It is a [PRD non-goal](prd.md#4-non-goals) and is recorded only so that nobody builds it by accident.

Each row covers one operation, because one integration can be fine to read and forbidden to automate.

| Verdict | Meaning | Product behaviour |
|---|---|---|
| `allowed` | A primary source permits this operation for the analyzed case. | May ship, subject to the row's conditions and FR-3.30 consent. |
| `user-assisted` | A person performs the consequential step. JobPilot prepares material or fills fields and stops. | Manual or Copilot only. JobPilot never submits. |
| `blocked` | A primary source forbids it, or a technical gate only the vendor or an employer can open stops it. | Not built. Code paths refuse it. |
| `unknown` | The source is ambiguous, silent, or could not be read. | **Behaves as blocked** until a primary source or written vendor answer resolves it. |

Rules for this register:

- Only primary sources (the vendor's own terms, docs, or policies) can set `allowed` or `blocked`. Forums, blogs by third parties, and Medium set nothing.
- `user-assisted` is not a grant of permission. Where the row says the source is silent, the verdict rests on a human doing the act, and on spec section 9 conditioning only Autonomous mode on verified permission (FR-9.6).
- Quotes are short and exact. Link markup and bold in the source are dropped. All dates read are 2026-11-01.
- Connectors and providers carry these four values as their policy-review status (FR-5.14). See [AI providers](ai-providers.md#capability-and-policy-vocabulary).

`claude -p` is the Agent SDK. The headless docs say the page "covers using the Agent SDK via the CLI (`claude -p`)" (https://code.claude.com/docs/en/headless). The Agent SDK clauses therefore govern programmatic use of the CLI.
