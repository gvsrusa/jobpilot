# JobPilot AI 0.1.0

Foundation release. Nothing job-specific exists yet. Status: not published; builds are unsigned.

## What was built

- Tauri desktop app with status, documents, data, and recovery views.
- Local SQLite database with versioned migrations, documents, and full-text search.
- Backup, restore, export, and delete-all, with an audit log.
- `jobpilot` command line (`status`, `doc`, `backup`, `data`).
- OS keychain secret storage. Secret values do not reach the webview, logs, or exports.

## Outstanding risks

- Builds are unsigned (Decision D3). Expect OS warnings.
- CJK search is not designed for or tested; results may be poor.
- Secrets recovery after restore or keychain loss is limited and not tested end to end on real keychains.
- A crash inside the restore swap leaves no startup warning. The `pre-restore` snapshot holds the prior data.
- `copy_dir` follows symlinks and blocks on a FIFO.
- A refused restore (another process holds the lock) still writes a `pre-restore` snapshot first.

## Installer check

The macOS arm64 `.dmg` was built locally, mounted, and the app launched from it on a temporary data folder. It created its data store and stayed running for 8 seconds. Nobody clicked through it. The x86_64 and Windows installers have not been launched.
